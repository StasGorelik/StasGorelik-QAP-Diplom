# Дипломный проект: Автоматизация тестирования REST API на Python

Данный проект содержит мою работу (дипломный проект), посвященную разработке фреймворка для автоматизированного тестирования UI API.

## 📌 Описание проекта
Основная цель проекта — внедрение автоматизации тестирования для проверки стабильности, безопасности и корректности работы серверной части приложения (API). Фреймворк построен на современных инструментах тестирования в экосистеме Python, легко масштабируется и изолирует логику тестов от конфигурационных данных.

Основные задачи автоматизации в проекте:
* Тестирование функционала авторизации и аутентификации пользователей.
* Проверка корректности ответов сервера (статус-коды, структура и валидация JSON-данных).
* Покрытие негативных сценариев и обработка ошибочных запросов.

---

## 🛠 Технологический стек
* Язык программирования: Python 3.10+
* Фреймворк для тестирования: Pytest
* Библиотека для HTTP-запросов: Requests

## Структура проекта

```text
├── core/                 # Базовый функционал, конфигурация и утилиты для работы тестов
├── models/               # Описание моделей данных (например, Pydantic-модели для API-тестов)
├── pages/                # Реализация шаблона Page Object Model (POM) для UI-тестов
├── services/             # Клиенты и классы для взаимодействия с тестируемыми API-сервисами
├── tests/                # Набор тест-кейсов (UI и API тесты)
├── .flake8               # Конфигурация линтера Flake8 для проверки стиля кода
├── .gitignore            # Список файлов и папок, игнорируемых системой Git
├── Dockerfile            # Инструкция для сборки Docker-образа и запуска тестов в контейнере
├── pytest.ini            # Основной конфигурационный файл фреймворка Pytest
├── README.md             # Документация и руководство по запуску проекта
└── requirements.txt      # Список зависимостей проекта (внешние библиотеки и пакеты)
---

## 🚀 Инструкция по локальному запуску

### 1. Клонирование репозитория
Bash

git clone https://github.com
cd StasGorelik-QAP-Diplom
git checkout hw_api

### 2. Развертывание виртуального окружения
Для изоляции зависимостей проекта рекомендуется использовать venv:
Bash

# Для Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Для Windows (в командной строке CMD)
python -m venv venv
venv\Scripts\activate

### 3. Установка необходимых пакетов
Установите зависимости, указанные в файле конфигурации:
Bash

pip install -r requirements.txt

## 🧪 Запуск автоматизированных тестов

Инструмент pytest автоматически обнаружит и выполнит тестовые методы в проекте.

* Запуск всего тестового набора:
  
bash
  pytest
  
* Запуск тестов с подробным выводом (Verbose режим):
  
shell

bash
  pytest -v
  
* Запуск конкретного модуля (например, тестов авторизации):
  
shell

bash
  pytest tests/test_auth.py
